Choose video, GIF or PNG

Pick a format for the job and diagnose common browser export problems.

By Teja Priyan · Updated 27 October 2026

Choose by purpose

Use video for a moving reveal with a useful running time. Popsel uses the browser’s MediaRecorder capabilities, so the available video container can be MP4 or WebM. An MP4 option is not a promise that every browser can encode it. Check the saved filename and play the result on the device or service where it will be used.

Use GIF for a small looping animation when broad image-style sharing matters more than detailed color or file size. GIFs can grow quickly with longer scenes and fine detail. Use PNG for a still frame or a before-and-after comparison; it does not preserve movement.

Run a small export first

Try a short clip with a sample image before working on a large slideshow. Keep the tab active and avoid changing controls during capture. Browser recording follows the rendering workload: selecting a 60 FPS capture target does not guarantee 60 distinct frames every second on all hardware.

When a download fails

If video capture is unsupported, try an up-to-date browser with MediaRecorder support, or use PNG while you investigate. If nothing appears after exporting, check the browser’s downloads list and whether downloads were blocked. A device running low on memory may fail on a long GIF or several large photos; shorten the animation or resize the source images.

If the saved video opens but looks wrong, replay it in another local player before uploading it elsewhere. Test a sample image to separate a browser or format issue from a problem with one photo. For a reproducible bug, send the browser version, chosen mode, duration and format through the Contact page. Do not send a private photo unless it is needed and you choose to share it.
